# Dap Ur Homies Wiki

Dap ur Homies 把玩家之间的互动做成服务端逻辑：碰拳、击掌、拥抱、抓取投掷、人盾、推搡、踢击。服务器装一个 jar，原版客户端直接进服，玩家不需要装任何模组。

这是上游 [Anteryo/Dap-ur-homie](https://github.com/Anteryo/Dap-ur-homie) 的非官方服务端移植版，只支持 Minecraft 1.21.11。
